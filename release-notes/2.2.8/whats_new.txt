Latest changes:
- Show version and build together in the main-screen header, such as 2.2.8(240). Keep Manage Storage in the top-level menu on both platforms.
- Include AOL surface tiles in MA package export and import. Remove the separate surface-package import menu entry.
- Follow the confirmed drone when its video and telemetry arrive. Panning releases map follow; zooming alone keeps it active.
- Keep the app and video telemetry running when Bluetooth is disabled. Warn that Bluetooth Remote ID broadcasts will not be detected.
- Show orange CAL for AGL/AOL when take-off coordinates are missing. Tap CAL for the 50-foot-above-take-off calibration panel; Disregard dismisses the panel without inventing a launch reference.
- For the video crosshair, show terrain MSL directly below the drone when looking straight down. When camera angle metadata is absent, label the assumption as Assumed down 90 degrees; honor reported angles when available. Long-press stores a terrain-MSL reference.
- Show point-specific AOL beside crosshair MSL when valid launch and surface data exist, without the main AOL display's 200-foot lateral search. Switching MSL/REF leaves point AOL unchanged.
- Correct Matrice camera-heading decoding so crossing east does not cause a large jump in the map FOV rays.
- Provide Tracker with completed-recording resolution, frame rate, codec, bitrate, duration, and file size when available. Tracker's matching update displays MB and refreshes source details without a manual reload.
- Recorded playback waits for the remote media connection, preserving opening frames. Reconnection does not rewind active playback. Tracks expire after 30 seconds without fresh RID or paired video telemetry.
- Capture clue camera metadata with the rendered frame. Keep missing camera information distinct from measured values.
- Manage Storage shows map/terrain and flight usage, editable size/age limits, and daily-folder inspection and deletion. Default flight limits are 10 GB and 30 days. Demand-based cleanup protects today and active files, targets 10% headroom, and offers Increase Allowance when protected data prevents cleanup.
- Enable Capture Streams by default for new settings, preserving saved choices. Pause capture under storage pressure and resume when space is available; restarting the media server can briefly interrupt video.

Platform-specific changes:
- Android uses legacy Bluetooth Remote ID scanning to match iOS; Wi-Fi RID scanning is disabled by default. Keep map-tile reads responsive while indexing removable storage.
- Android uses one cyan crosshair label on a fitted dark background for readable MSL/AOL text. Improve recorded-video frame-rate fallback and source metadata extraction.
- Android starts microphone capture only after permission and explicit enable, reports capture failures accurately, and clears remote-viewing and microphone indicators when a session ends.
- iPad removes the duplicate Settings Import Config link and uses a dedicated stream touch layer for taps, double taps, long presses, pinch and pan.
- iPad reads completed-video properties asynchronously and caches them. New artifacts use RID2Caltopo/FlightStorage/local-date folders. Existing CapturedStreams, Tracks, Logs and Clues folders remain in place; in-place updates preserve them. No uninstall is required.

Known platform differences:
- Android retains the selected Archive Dir and document-provider support. Apple previews stored files with Quick Look; Android uses available viewers. Some Android providers cannot report free space.
- Map/terrain storage has separate limits; AOL packages and active terrain are protected from ordinary cache trimming. Surface data must cover the flight location, and valid altitude references are still required.
- iOS may suspend video/anomaly processing while locked or backgrounded. Wi-Fi RSSI and Person Relevance filtering remain unavailable on iOS.
