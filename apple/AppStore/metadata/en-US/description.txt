RID2Caltopo helps search-and-rescue and incident teams receive and organize drone Remote ID observations in the field.

CalTopo and r2c-tracker are optional integrations. Users configure their existing authorized service access when they choose those features. Local Remote ID monitoring, archives and controller-video analysis do not require either account.

The app implements ASTM F3411 Remote ID reception over Bluetooth, including Wi-Fi Beacon and Wi-Fi NAN observations relayed by a DroneScout DS110. It does not directly scan Wi-Fi Remote ID. Compatible direct Bluetooth transmitters need no bridge. Nearby aircraft, tracks, transport details, signal strength, altitude, range, and traffic separation are presented in an operator-focused interface.

Organization access is set up through tracker enrollment links or QR codes and authenticated sign-in. Map tile packages and Remote ID mappings can be imported without transferring credentials. Imported mappings give team aircraft familiar operational labels.

Optional tracker coordination lets multiple field devices coordinate aircraft ownership. Operator-confirmed tracks can be published to a configured CalTopo team map while non-owner devices relay observations instead of publishing duplicates.

RID2Caltopo also embeds MediaMTX for local controller-video ingest. Live video can be viewed with the anomaly detector disabled, or analyzed with visible-light Color Uniqueness and infrared detector modes.

Local Maps organizes flight plans, original photographs, and reconstructed 2D maps and regional 3D surfaces. Mission planning includes supported DJI aircraft and optional Pilot 2 transfer through DJI's Cloud API. Controller transfer requires compatible equipment; local reconstruction requires suitable original photographs.

Core hardware interoperability uses supported broadcast and streaming protocols. Verified examples include DJI and Autel Robotics controller video and BlueMark Innovations / DroneScout relays. These examples do not guarantee compatibility with every product from those manufacturers.

Local diagnostic logs and GeoJSON archives can be exported through the system share sheet. Configured tracker services can receive eligible team tracks and media catalog previews. Full remote viewing and recording transfers use per-request approval by default; enabling Remote Video Control provides advance authorization for supported requests. Microphone use is separately enabled for VoIP.

RID2Caltopo is intended for trained incident personnel. It does not replace visual observation, see-and-avoid responsibilities, or compliance with aviation regulations.
