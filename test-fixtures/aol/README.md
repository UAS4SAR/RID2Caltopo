# Surface contract fixtures

`complete.aol`, `hole.aol`, `bad-checksum.aol`, `bad-reference.aol` and
`bad-units.aol` are synthetic fixtures generated by `tools/aol/make_fixtures.py`.
Never import them for operations.

`nevada-city-1m.aol` is a public USGS lidar-derived regression sample. It is not
bundled or activated in either mobile app. The package manifest retains source
URL, acquisition range, CRS and original input checksum. Both platform tests
read this identical package without internet access. See
`docs/AOL_Implementation_Validation.md` and `tools/aol/README.md` for provenance,
preparation, observed limitations and qualification status.
