R2C Mapping

Connecting to the R2C tablet…

1. Load the flight route

Download this flight route, then import it in Pilot 2 → Flight Route. Choose M4D → M4TD and review the camera, route and clearance before flight.

The KMZ contains the capture pattern. Review these flight parameters in Pilot 2:

    Mission record

    Contains the R2C mission record, boundary and flight route. Pilot 2 imports mission.kmz.

    2. Return original photos

    After landing, download the aircraft's original photos in Pilot 2. Select this flight's JPEGs below. They go directly to this mission on the R2C tablet.

    Selecting the same files resumes an interrupted upload and skips verified duplicates. Originals remain on both devices.

    Keep R2C open on the tablet and both devices on the same Wi-Fi. This page cannot start or control the aircraft.
